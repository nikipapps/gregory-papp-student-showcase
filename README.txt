PREVIEW
Open index.html in a browser. Keep all HTML files, style.css, and the
images folder together so relative image and stylesheet paths work.

PUBLISH WITH GITHUB PAGES
1. Create or open a repository under your GitHub account.
2. Upload the CONTENTS of this folder (not an extra enclosing folder).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. Wait for the Pages deployment, then open the URL shown in Settings > Pages.
7. Test all four pages and image loading on the published site.

PRIVACY
The public contact page lists an email address only. A personal mobile number
was intentionally left off the public site. Review the email address before
publishing if you prefer not to receive public messages.
